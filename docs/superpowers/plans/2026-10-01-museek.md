# Museek Implementation Plan

> **For agentic workers:** Use native implementation with independent backend and Windows-integration tasks, then review the complete app.

**Goal:** Deliver the Windows 11 audio player and trimmer described by the user.

**Architecture:** A native WPF window owns interaction state, a small range model validates selection, VLC provides playback, and a separate FFmpeg service probes/exports files. Per-user Windows registration is isolated from playback.

**Tech Stack:** .NET 10, WPF, LibVLCSharp, VLC 3, FFmpeg.

**Spec:** ../specs/2026-10-01-museek-design.md

## Global Constraints

- Windows 11 x64; source files remain intact.
- Output WAV, MP3, FLAC, M4A, OGG or Opus.
- No Windows association changes during development.
- Ship a runnable self-contained publish folder at dist/Museek.

## Review Focus

- Paths containing spaces, apostrophes and Unicode open/export correctly.
- Corrupt media and files without audio produce readable errors.
- Dragged endpoints remain ordered, including very short audio.
- Cancellation removes incomplete exports and preserves existing destinations.
- Opening another file or closing during loading/export cannot leave an orphaned process.
