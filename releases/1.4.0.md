# Museek 1.4.0

- Added **Check for updates** to the Help menu. The update dialog shows your installed version and checks GitHub for a newer stable Museek release.
- When an update is available, choose **Download update** to download it with progress and cancellation. Museek checks the release checksums and installer version before offering **Install update**.
- Installation closes Museek and opens Setup. Setup waits for the updating app to finish closing before replacing files. Close any other Museek or tag editor windows first, then follow Setup's steps.
- Update checks, downloads, and installation happen only when you request them. Your settings and audio files are kept.

Install this version over your existing Museek installation to get the new Help menu option.
