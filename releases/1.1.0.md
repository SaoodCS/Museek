# Museek 1.1.0

## Changes

- Install Museek with a setup wizard. Run a newer installer to update the existing installation, and uninstall through Windows Installed apps or the installed `uninstall.exe`.
- Upgrade installations made by the previous PowerShell installer. Settings and audio files are preserved.

## Included features

- Open audio from File Explorer, play/pause, adjust volume, seek and stop playback.
- Display embedded album artwork, song title, artist and album.
- Trim a selected range and save a separate audio copy.
- Choose Museek for audio file types through Windows Settings and enable single-window mode from Tools.
- Enable an **Edit Tags** command in Explorer's **Show more options** menu. Edit one or more files' tags and add, change or remove album artwork without re-encoding the audio.

## Install or update

Download and run **Museek-1.1.0-setup.exe**. Close Museek and its tag editor windows before updating. The installer includes the .NET runtime, VLC and FFmpeg and installs for your Windows account without administrator rights.

Requires **Windows 11 x64**. The app is currently unsigned. Museek has no in-app updater; install a newer release to update it.
