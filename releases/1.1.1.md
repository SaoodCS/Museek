# Museek 1.1.1

## Changes

- About Museek now displays the actual release version from the app's build metadata, keeping it correct for future releases.

## Install or update

Download and run **Museek-1.1.1-setup.exe**. Close Museek and its tag editor windows before updating. Setup updates the existing installation and keeps your settings and audio files.

Requires **Windows 11 x64**. The installer includes the required runtimes and audio tools.
