# Museek 1.2.0

- Reduced allocations during playback and seeking by reusing frozen icons and updating only the elements that changed.
- Bounded the temporary pixel buffer used to validate large artwork while still checking the entire image.
- Reduced memory use when editing files with identical artwork, and streamlined batch tag refreshes.
- Tag saves recover from a temporary Windows file-replacement refusal while retaining conflict checks, cancellation, and atomic replacement.
- Grouped the player window source by responsibility and removed obsolete planning documents.
- Build packaging now uses a fresh payload and keeps the previous build if publishing fails.
- Added repeatable allocation checks alongside the existing playback, trimming, tag preservation, installer, and release checks.

Local warmed checks recorded 88% fewer managed allocations across 10,000 seek updates and 99.6% fewer during 4096×4096 artwork validation. These measurements cover managed allocations, rather than total process memory.

Install this version over your existing Museek installation. Your settings and audio files are kept.
