# Museek 1.3.0

- Added **Sort By** to the top menu with Title, Artist, Album and Genre. One option is checked at a time; Title is selected by default.
- Added **Previous track** and **Next track** buttons to play audio from the current file's folder in the selected alphabetical order. Navigation stops at the first or last track.
- Title sorting uses the filename when the title tag is missing. Missing artist, album or genre tags sort last, with titles breaking ties.
- The track buttons are hidden in trim mode. The player keeps its compact layout without a folder list or library view.

Install this version over your existing Museek installation. Your settings and audio files are kept.
