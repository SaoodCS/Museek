# Museek 1.3.2

- First playback now uses a VLC plugin cache generated and checked against the bundled decoder. This reduces the plugin discovery work when you first open audio. Initialization stays in the background, and normal scanning remains available if a cache is missing or invalid.
- Installation and updates preserve the plugin timestamps required by the cache. Checks cover installed playback, relocated files, and recovery from missing, corrupt, or stale caches.
- Fixed a tag-editor artwork memory issue: portrait and landscape previews now fit within 420 pixels in both dimensions without enlarging small images. Source dimensions are checked before pixel decoding. The original artwork bytes are preserved when saving tags.

Install this version over your existing Museek installation. Your settings and audio files are kept.
